## 1. Selection rules

Select the archetype from the semantic structure of the approved copy.

| Approved content | Preferred visual |
| --- | --- |
| One decisive statement | Full hero or centered statement |
| Four capabilities | 2x2 icon cards |
| Five capabilities | 2x2 plus one emphasized vertical card |
| Six capabilities | 3x2 icon cards |
| Before and after | Two large panels with directional flow |
| Old versus new | Comparison table or split contrast |
| Sequential stages | Timeline, funnel, or connected cards |
| Central intelligence and local units | Hub with orbiting nodes |
| Provided metrics | Large-number cards or a supplied-data chart |
| Price and condition | Price card plus condition panel |
| Dashboard indicators | Product-style dashboard mockup |
| One number with activities | Animated ring plus icon bullet grid |

Do not force every list into identical cards.

## 2. Archetypes

### Cover

- red institutional hero;
- Colli&Co plus client lockup if client logo is supplied;
- title in lower half;
- no footer logo;
- three glass spheres maximum.

### Editorial grid

- light background;
- eyebrow and large heading;
- content cards fill most of the usable vertical area;
- use 2x2, 3x2, or asymmetric 2x2 plus highlight.

### Statement

- red or dark background;
- one sentence only;
- centered or left aligned;
- one abstract visual, orbit, sphere, or line system.

### Comparison

- large heading;
- two-column table or two panels;
- use checks and meaningful contrast;
- increase row height so the table occupies the slide.

### Metric wall

- five or fewer figures;
- large digits;
- one highlighted result;
- supplied period caption;
- cards must be tall enough to avoid dead lower space.

### Process

- connected horizontal stages for up to six steps;
- vertical or two-row process for more stages;
- equal card heights;
- icon per stage;
- emphasize the final business outcome.

### Hub and network

- central radial-gradient circle;
- dashed orbit;
- nodes positioned symmetrically;
- independent float animation;
- never rely on `nth-child` when non-node elements are siblings;
- assign explicit positional classes such as `node-nw`, `node-ne`, `node-sw`, `node-se`, and `node-s`.

### Important allocation slide

- one dominant animated number or ring;
- supporting points in icon cards;
- motion must emphasize the metric, not distract from the copy.

### Closing

- red institutional hero;
- central closing statement;
- client and Colli&Co lockup if supplied;
- no new promise or call to action unless present in approved copy.

## 3. Background cadence

Plan the deck as a rhythm, not isolated screens.

Good default sequence:

1. red cover;
2. light evidence;
3. red statement;
4. light diagram;
5. red authority;
6. white brand;
7. light comparison;
8. light knowledge;
9. dark local context;
10. light metrics.

Continue varying treatment. Avoid more than two consecutive slides with both the same background and the same composition.

## 4. Text transformation rules

Allowed:

- break a sentence across lines;
- convert a list into labeled icon cards;
- convert supplied pairs into comparison rows;
- convert supplied numbers into data cards;
- shorten repeated grammatical scaffolding when every original concept remains visible.

Not allowed:

- add explanatory subtitles;
- name a methodology not present in the copy;
- add performance claims;
- add city names, examples, or audiences;
- infer missing numbers;
- create generic closing calls to action.

Paragraph handling:

- one sentence may remain as a short lede;
- two or more parallel ideas should become separate blocks;
- a long sentence should use typographic line breaks before reducing size;
- never leave a single word on the final line.

## 5. Data integrity

Charts may use only supplied data. If data is insufficient for a chart:

- use a large metric;
- use a flow;
- use a qualitative diagram;
- keep the original table.

Do not invent axes, periods, baselines, percentages, or trend direction.
